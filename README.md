# Password Strength Checker

A simple Python program that checks whether a password is strong or weak.

## Features
- Checks minimum length (8 characters)
- Checks for at least one uppercase letter
- Checks for at least one lowercase letter
- Checks for at least one digit
- Shows the reasons if the password is weak

## How to Run
1. Install Python 3
2. Clone this repo:
```
git clone https://github.com/pranavkhandale/password-generator.git
```
3. Run the file:
```
python password-generator.py
```

## Example
```
Enter Password: hello
Weak Password
Reasons:
- Password must be at least 8 characters.
- Add at least one uppercase letter.
- Add at least one digit.
```
